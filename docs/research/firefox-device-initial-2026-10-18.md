# Первичная проверка B8000-H, 18 октября 2026

SSH доступен как `user@b8000h`. Архитектура `armv7l`, физическая память
MemTotal 1018988 КиБ (около 995 МиБ), zram 512 МиБ.

Установлены `b8k-firefox 1.3.0-r0`, `firefox 151.0.3-r0`,
`mobile-config-firefox 5.4.1-r0`, `earlyoom 1.9.0-r0`.
SHA256 установленного helper, команды подготовки профиля и файлов
`b8k-ram.js`/`b8k-lean.js` совпадают с локальными файлами релизного коммита.
uBOL `2026.1012.1545` отмечен активным в метаданных профиля.

В установленном `b8k-ram.js` сохранены исходные настройки: встроенная выгрузка,
порог 10%, минимальный возраст неактивной вкладки 60 секунд. В просмотренных
`user.js` и `prefs.js` экспериментальные параметры отсутствуют. Это проверка
файлов на диске; значения в работающем Firefox через API не запрашивались.

## Пассивное наблюдение текущей сессии

Firefox пользователя не перезапускался, страницы не переключались,
настройки и пакеты планшета не менялись. Это наблюдение уже открытой сессии,
не стандартизованный benchmark и не A/B-сравнение.

Семь выборок за 30.52 секунды, суммарно по восьми процессам Firefox:

- PSS: 388.28–388.31 МиБ.
- SwapPss: 0 МиБ.
- CPU-time сохранявшихся процессов: около 0.02 секунды за интервал.
- MemAvailable в конце: 420.53 МиБ.
- Использование swap всей системой: 88.67 МиБ; этот объём не относится
  к текущим процессам Firefox, у которых SwapPss равен нулю.

Вывод ограничен текущей тихой сессией. Эти числа не доказывают экономию от
обновления или от какого-либо экспериментального ограничения. Для сравнений
нужны одинаковые страницы, перезапуски и повторы по
[аппаратному плану](../device-validation.md). Рабочая сессия оставлена открытой;
для следующего этапа запрошено закрытие Firefox пользователем после сохранения
нужных данных.
